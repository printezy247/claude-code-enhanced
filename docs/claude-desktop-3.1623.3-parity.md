# Claude Desktop 3.1623.3 — parity review of the Claude Code surface

The review of the **Claude Desktop 3.1623.3** build, and the gap list between it
and CCE (Claude Code Enhanced). It replaces
[`claude-desktop-parity.md`](claude-desktop-parity.md), which reviewed the
**2.42304.2** build (SDK 0.3.299) and is kept only as history.

Everything below was measured on this machine. Where a number comes from the
static analysis it is marked **[REA]**; where it comes from a string scan of
the unpacked bundle it is marked **[scan]**; where it comes from CCE's own
source it is marked **[CCE]**.

### 1.3 The connector permission policy **[scan]**

The desktop has a **four-state** policy for connector tools:

```js
["allow", "ask", "ask-session", "blocked"]
```

`ask-session` is "ask once per session": the user approves the tool, and the
approval holds for the rest of that session. The per-session state lives in
`enabledMcpTools`, `withheldConnectorHosts`, `pendingToolPermissions`,
`chromePermissionMode`, `mcqAnswers`, `steeringGates` and `sessionMentions`.

The desktop keeps the connector track **separate from the session permission
mode** — `chromePermissionMode` sits next to `permissionMode` — so "skip all
prompts" does not silently allow a connector that the user marked as "ask".

### 1.7 The SDK 0.3.303 → 0.3.308 delta (measured, not assumed)

The SDK moved from **0.3.303** (what CCE had installed) to **0.3.308** (what
the desktop ships) in this pass. The `Options` type in `sdk.d.ts`:

| | 0.3.303 | 0.3.308 |
|---|---|---|
| Option keys in the type file | 57 | **69** |

The 12 keys the 0.3.308 type file adds are exactly the ones 0.3.303 accepted
at runtime but did not declare: `debug` · `debugFile` · `managedSettings` ·
`sandbox` · `settings` · `settingSources` · `skills` · `spawnClaudeCodeProcess` ·
`stderr` · `strictMcpConfig` · `systemPrompt` · `title`.

So the bump buys **no new capability** — every option CCE now passes was
already accepted by the installed 0.3.303. What it buys is that the options
CCE relies on are now **typed**, and a future SDK release that drops one is a
type error instead of a silent no-op.

The 0.3.308 runtime also adds `forwardNestedSubagentToolCalls` (still
untyped), and the context-usage surface grows `recommendations[]` and
`fix{keys,messages}`.

## 3. What is deliberately not built, and why

| Not built | Why |
|---|---|
| The 35 internal `ccd_*` and product MCP servers | They are the desktop's own product surface, not Claude Code features. The CLI already ships its own tools. |
| The claude.ai connector directory | Needs an Anthropic-org backend and claude.ai auth. CCE is a local CLI wrapper. |

| Computer use and Chrome | Need native helpers, a TCC permission flow and a browser extension install. |
| SSH and WSL remote sessions | Need `ssh2`, an askpass binary and remote process reattach. |
| Artifacts share/publish | Needs an Anthropic backend and an org entitlement. |

| The Grand Prix password-manager pairing | An unrelated product. |
| The Office 365 and GitHub bundled MCP binaries | 26 MB of binaries; the CLI's own MCP config already covers these. |
| `skills: 'all'` | It auto-allows every `Skill` tool. That is a policy change the user has to ask for, not a default. |
| `permissionPrompts: 'none'` | It removes the permission card that CCE exists to provide. |

## 5. Verification

```bash
cd "/home/jack/Documents/Default Project/claude-code-enhanced"
npm test          # the whole suite
npm run lint
npm run vendor    # regenerate the renderer vendor bundle after a renderer change
npm run smoke
npm run dist      # the deb + the AppImage
```

Behavioural checks:

- **Managed policy** — put a `managed-settings.json` in
  `/etc/claude-code/`, start a chat, and the engine applies it
  (`claude --debug` shows the `--managed-settings` flag).
- **Scoped connectors** — set `scopedMcpServers` to one server name: the chat
  sees that server's tools and not the others.
- **Ask once per session** — set a tool's policy to `always_ask_session`: the
  first call asks, the rest of the chat does not, and a new chat asks again.
- **Destructive connector tool** — a tool whose name says it deletes or
  writes always asks, even when the tool is set to `always_allow`.
- **The git surface** — `git:diff`, `git:diff-stats`, `git:commits` and
  `git:commit-diff` return what the same git commands return in a terminal.
- **The MCP client** — an HTTP connector's `tools/list` round-trips through
  the host client.

```bash

  /var/cache/apt/archives/claude-desktop_3.1623.3_amd64.deb /tmp/claude-31623

  /tmp/claude-31623/usr/lib/claude-desktop/resources/app.asar \
  --format json --max-heap-mb 3072 > rea-31623.json
```

The run takes about twelve minutes and produces a ~225 MB evidence file. The
